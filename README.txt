JAYMIE — site statique pour GitHub Pages
========================================

Fichiers
- index.html : contenu de la page
- style.css : design et mise en page
- assets/ : place ici tes images

Images à ajouter dans assets/ (JPG recommandé)
- hero.jpg             : grande photo de groupe pour l'en-tête
- blind-cover.jpg      : pochette de la démo Blind
- jaymie-blue-cover.jpg: pochette de l'album éponyme / album bleu
- between-cover.jpg    : pochette de Between a Shadow and I
- photo-01.jpg         : première photo d'archive
- photo-02.jpg         : deuxième photo d'archive
- photo-03.jpg         : troisième photo d'archive

Si une image n'est pas encore présente, un emplacement de remplacement apparaît.
Les noms doivent correspondre exactement, y compris les minuscules et les tirets.

Publication sur GitHub Pages
1. Crée/connecte-toi à https://github.com/
2. Crée un dépôt PUBLIC nommé exactement : TONNOMUTILISATEUR.github.io
3. Téléverse index.html, style.css et le dossier assets/ à la racine du dépôt.
4. Dans le dépôt, ouvre Settings > Pages.
5. Sous Build and deployment, choisis Deploy from a branch.
6. Sélectionne la branche main et le dossier /(root), puis Save.
7. Attends quelques minutes, puis ouvre https://TONNOMUTILISATEUR.github.io/

Personnalisation
- Dans index.html, remplace les liens provisoires (écoute, contact) par les tiens.
- La biographie et les crédits sont volontairement génériques : vérifie les faits avant publication.
- Vérifie que tu as les droits ou autorisations nécessaires pour publier les photos et enregistrements.
- Tu peux modifier les couleurs dans style.css, dans la section :root.
- Aucun outil de build n'est nécessaire; le site est en HTML/CSS simple.
